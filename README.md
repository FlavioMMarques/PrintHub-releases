# PrintHub: versões

Instaladores publicados do PrintHub. Os PCs com o PrintHub instalado se atualizam sozinhos por aqui: cada versão traz o instalador, o `manifesto.json` e a assinatura `manifesto.json.sig`, conferida pelo Agente antes de instalar.

Até a 0.4.7, o produto se chamava RotaPrint. A partir da 0.5.0, o nome é PrintHub, com outro instalador e outra chave de assinatura. Por isso, um PC com o RotaPrint não se atualiza para o PrintHub: é preciso desinstalar o RotaPrint, apagar `C:\ProgramData\RotaPrint` e instalar o PrintHub.
